# Forensic CV Manager 2.4.0

## Added
- Click-to-sort column headers on record tabs.
- Repeated clicks toggle ascending and descending order.
- Type-aware sorting for dates/years, numeric training hours, Yes/No Core Training, and natural text ordering.
- Blank values remain at the bottom.

## Notes
- Sorting affects only the on-screen record list; it does not change SQLite data or generated CV ordering.
